## 3. Conceitos centrais de DevOps introduzidos

### Versionamento e Deploy
- Controle de versões permite recuperar versões antigas, colaborar em equipe e trabalhar com branches (ramificações).
- Deploy é o processo de implantação de uma aplicação em produção.
- Ferramentas citadas: GitHub, GitLab, Bitbucket.

### Pipelines e Automação
- Pipeline = sequência automatizada de etapas (compilação, testes, análise de código, deploy).
- Reduz erros humanos e agiliza o feedback à equipe.

### Integração Contínua (CI)
- Prática de integrar alterações frequentemente, disparando builds e testes automáticos.
- Identifica problemas cedo e reduz conflitos entre versões.

### Qualidade de Software
- Ferramentas automatizadas avaliam padronização, segurança, complexidade, cobertura de testes e vulnerabilidades.
- Quanto antes um problema é detectado, menor o custo de correção.

### Testes Automatizados
- Categorias: unitários, integração, funcionais e end-to-end.
- Executados automaticamente dentro do pipeline de CI/CD.

### Entrega Contínua (CD)
- Após aprovação nos testes, o sistema fica pronto para publicação.
- Benefícios: menor tempo de entrega, mais estabilidade, menor risco.

### Containers e Estratégias de Implantação
- Containers (ex: Docker) padronizam o ambiente de execução em dev, testes e produção.
- Estratégias de deploy: Rolling Update, Blue-Green Deployment, Canary Release — todas reduzem indisponibilidade e facilitam rollback.

## 5. Critérios de avaliação
Fórmula da média: **(P1 × 0,25) + (P2 × 0,25) + ((PJ + AT) × 0,25)**
- P1 = Prova 1
- P2 = Prova 2
- PJ = Projeto
- AT = Atividades

## 6. Atividade proposta
1. Formar grupos de 3 a 5 integrantes (composição fixa para as atividades semanais).
2. O grupo deve se reunir semanalmente para realizar as atividades da aula.
3. Criar um repositório no GitHub (diretório principal do semestre) com um arquivo `.md` resumindo a Aula 01.
4. Responder à avaliação diagnóstica da primeira aula.
