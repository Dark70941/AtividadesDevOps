## Lista de Tarefas e Repositórios

### Tarefa 02 — Versionamento com Git, GitHub, Commits e Tags
* **Descrição:** Criação de projeto web (`index.html`, `style.css` e `script.js`), configuração do Git no VS Code, publicação no GitHub, registro de modificações via *commits* e criação de versões utilizando *tags*.
* **Repositório:** [nicollylemos/LivrariaDevOps](https://github.com/nicollylemos/LivrariaDevOps)
* **Link da Entrega (Teams):** [Acessar Entrega](https://github.com/nicollylemos/LivrariaDevOps?classId=5aed53b5-0fe7-48a3-a344-3d44b238d22a&assignmentId=2f8f7cff-27e4-44bb-a738-e37db265dae3&submissionId=a7d93a88-f8a7-d472-2a70-3ca978a1a6fc)

### Tarefa 03 — Projeto React Baseado em Template e Deploy na Vercel
* **Descrição:** Importação e customização de um template de projeto desenvolvido em React, versionamento no GitHub e publicação (deploy) na plataforma Vercel.
* **Repositório:** [nicollylemos/ProjetoGitTemplate](https://github.com/nicollylemos/ProjetoGitTemplate)
* **Link da Entrega (Teams):** [Acessar Entrega](https://github.com/nicollylemos/ProjetoGitTemplate?classId=5aed53b5-0fe7-48a3-a344-3d44b238d22a&assignmentId=da570331-b12b-4c4b-9d0d-e75d97549b0a&submissionId=9da05f14-3089-0b3d-786f-e19d1f765718)

### Tarefa 05 — Pipeline Automatizada com GitHub Marketplace Actions
* **Descrição:** Seleção de 3 Actions do GitHub Marketplace e desenvolvimento de uma pipeline automatizada no GitHub Actions, validando e documentando cada etapa do workflow.
* **Repositório:** [Dark70941/projetodevopspipeline](https://github.com/Dark70941/projetodevopspipeline)
* **Link da Entrega (Teams):** [Acessar Entrega](https://github.com/Dark70941/projetodevopspipeline?classId=5aed53b5-0fe7-48a3-a344-3d44b238d22a&assignmentId=edf62009-a490-4cd0-a436-18f80495b5d2&submissionId=7e4daa4a-9ece-4306-da6b-f9cac759b9e9)

### Tarefa 06 — Pipeline CI no Push da Main e Análise de Repositórios
* **Descrição:** Configuração de pipeline no GitHub Actions disparada automaticamente a cada `push` na branch principal (`main`), acompanhada da análise técnica de pipelines em repositórios públicos do GitHub.
* **Repositório:** [Dark70941/projetodevopspipeline](https://github.com/Dark70941/projetodevopspipeline)
* **Link da Entrega (Teams):** [Acessar Entrega](https://github.com/Dark70941/projetodevopspipeline?classId=5aed53b5-0fe7-48a3-a344-3d44b238d22a&assignmentId=77cbe2b8-c1d3-46ee-a926-c3d4c0ba3cfb&submissionId=9464b174-5e24-585e-2853-d1528e3e7745)

### Tarefa 07 — Testes Automatizados na Pipeline de CI
* **Descrição:** Implementação de testes automatizados (unitário, integração e performance) executáveis de forma independente e integrados a um workflow de Integração Contínua (`.yml`) no GitHub Actions.
* **Repositório:** [nicollylemos/Atividade07DevOps](https://github.com/nicollylemos/Atividade07DevOps)
* **Link da Entrega (Teams):** [Acessar Entrega](https://github.com/nicollylemos/Atividade07DevOps?classId=5aed53b5-0fe7-48a3-a344-3d44b238d22a&assignmentId=59552c63-7dfa-4411-bd05-e993ae30ea6d&submissionId=8962afa0-9ee5-65f5-39aa-5542067771d0)

### Tarefa 09 — Documentação de Software e README.md
* **Descrição:** Elaboração da documentação técnica e de projeto (objetivo, escopo, requisitos, arquitetura, tecnologias) e estruturação completa do arquivo `README.md` com instruções de instalação, configuração, testes e deploy.
* **Repositório:** [tutuca07segundo/EcommercePWA](https://github.com/tutuca07segundo/EcommercePWA)
* **Link da Entrega (Teams):** [Acessar Entrega](https://github.com/tutuca07segundo/EcommercePWA?classId=5aed53b5-0fe7-48a3-a344-3d44b238d22a&assignmentId=7199f1fe-d6e1-406f-b090-91bf0d480b57&submissionId=3d0aa108-c0f3-98d9-8a6d-e58275f8c7fe)
